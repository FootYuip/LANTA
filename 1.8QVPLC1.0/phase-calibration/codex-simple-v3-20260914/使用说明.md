# 精简操作接口 v3

原镜像和 v2 未修改。本目录没有自动导入脚本。以已安装 v2 为前提。

## 只复制两个对象

1. 新建普通 GVL，名称 GVL_PhaseCalSimple，把“复制代码/GVL_PhaseCalSimple.declaration.txt”复制到声明区。
2. 替换现有 PRG_PhaseCalibration，分别复制同名 declaration.txt 到声明区、implementation.txt 到实现区。

原 GVL_PhaseCal、FB_PhaseTriangle、FB_PhaseFit、READ_485、SecurityCheck 均保留，不重复添加任务调用。今后只在 GVL_PhaseCalSimple 操作；旧 GVL 的三个命令每周期被新接口覆盖，不再从旧入口启动。

## 日常四个输入

- lrBeamWidthDeg：半功率全宽，度，两轴共用。实际两轴宽度不同时需另行扩展，不要取平均。
- lrAzGainDb：当前方位增益，dB。
- lrElGainDb：当前俯仰增益，dB。
- lrPhaseDeg：当前公共旋转角，度。

例如设备真实参数是 1°、60 dB、60 dB、247°，就分别填写 1、60、60、247。60 dB 对应电压乘数1000，不再按60倍处理。必须是设备真正的幅度dB定义，不能把档位当dB。

固定标定标准为0.2倍全宽对应1 V，自动读取机械角并按v2进行投影。输入只在开始沿且空闲时锁存。日常不再填写增益单位、拉偏比例、目标电压等。

操作只有 xStart、xAbort、xReset。开始为FALSE→TRUE沿，随后写回FALSE；故障时先保持开始FALSE，空闲复位TRUE再FALSE。普通写值，不强制。

只读看 wsMessage、xBusy、xFault、xResultValid；结果为 lrNewPhaseDeg、lrNewAzGainDb、lrNewElGainDb。只有xResultValid=TRUE才可使用。不会自动写回接收机，也不会自动修改伺服参数。

## 一次性设备配置不能省略

原GVL_PhaseCal现在作为内部调试区，不是日常填写页面。保留既有设备对应关系和运动约束，不为了简化页面擅自放宽限制。

首次仍须确认 iGainOrder、iPhaseDirection、lrRxDelaySec，以及最大机械偏置/速度/加速度；lrGainMin、lrGainMax必须按dB重新确认，不能沿用原来线性倍数的物理含义。本版开始时固定iGainUnit=1，范围数值不自动改写。

上一张截图的0.1°最大偏置和0加速度仍会拒绝1°波束的5.7秒方案。精简界面不会解除这两个真实限制：当前约35.9°俯仰下需要方位偏置约0.2468°，约0.421°/s速度、1.178°/s²加速度。请由设备调试确定可用范围或调整内部时长，不应让日常操作者试填。

默认仍是5.7秒规划流程，样本不足仍判无效。本次只改变操作入口和错误提示，没有修改轨迹、采样和拟合算法。首次设备关系未确认、硬件性能未知时，不能保证只填四项即可直接运行。
