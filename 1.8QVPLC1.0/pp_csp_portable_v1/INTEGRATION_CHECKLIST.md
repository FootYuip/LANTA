# 蓝塔接入检查单

本清单用于后续把独立模块接入蓝塔项目；当前版本尚未接入原镜像。

## 原上位机兼容

- [ ] HR 中 `iMode=0/1/2/4/6/7` 的数值和地址不变。
- [ ] 指向目标、程引轨道表、UTC、速度参数的编码和字序不变。
- [ ] IR 的模式、实际位置、实际速度、电流、故障、限位和理论角地址不变。
- [ ] 原 PID 使能反馈位定义为兼容状态，并形成书面说明。
- [ ] 同一时刻仍只允许一个 Modbus 主站写 HR。

## PP 指向

- [ ] 用户角度经站点坐标层转换为绝对电机计数。
- [ ] 软限位在进入动作层之前完成钳位或拒绝。
- [ ] PP 参数 6081/6083/6084 单位已与电机确认。
- [ ] 6060=1 在 6/7/15 之前生效。
- [ ] 6040=31 仅形成新设定点上升沿。
- [ ] 到位同时检查 6041.Bit10、位置误差和速度稳定时间。

## PP 到 CSP

- [ ] 上位机先以 iMode=2 指向预置点。
- [ ] 上位机确认误差和速度后才切 iMode=4。
- [ ] iMode=4 上升沿只锁存一次 PP 预置绝对点。
- [ ] CSP 保持目标来自该锁存点，不来自实际位置或上一拍累加。
- [ ] 6060=8 之前/同时已把固定保持点写入 607A。
- [ ] CSP 进入后保留约 4~5 秒接收、校验未来轨迹。

## CSP 程引

- [ ] `xTrajectoryActive` 只在正式任务时间到达后置位。
- [ ] 轨迹点是绝对位置，不是每周期增量。
- [ ] 时间戳严格递增，轨道表连续且有足够前视点。
- [ ] 首个轨迹点与固定预置点差值不超过 `diMaxCspStep`。
- [ ] 后续点与上一条已接受命令的差值不超过 `diMaxCspStep`。
- [ ] 轨迹中断后冻结最后安全点并 Halt，不跳回原预置点。
- [ ] FB 调用周期与 CANopen SYNC 周期一致，并测量任务抖动。

## 停机、下电和故障

- [ ] iMode=7 使用受控 Halt，速度稳定为零后保持使能。
- [ ] iMode=0 先 Halt，速度稳定为零后下使能。
- [ ] 故障复位 6040.Bit7 是明确的低-高-低边沿。
- [ ] 急停、硬限位、抱闸仍由独立安全层最高优先级处理。
- [ ] 603F、心跳、EMCY 和本模块错误号映射到原 Error_code/扩展诊断。

## 现场验证顺序

- [ ] 离线编译和变量类型核对。
- [ ] 断开动力或脱离负载，验证 PDO 与状态机。
- [ ] 单轴低速小角度 PP。
- [ ] PP 固定点切 CSP，保持数分钟确认无单向漂移。
- [ ] 人工连续小步 CSP，验证跳变拒绝。
- [ ] 低速短程程引，再逐步扩大范围和速度。
- [ ] 三轴联调、通信中断、轨迹空表、模式切换和急停测试。
